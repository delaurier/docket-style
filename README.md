# Docket style

Docket is a UI style for React and Tailwind CSS v4. It's quiet and precise, and built for keeping records:
- near-monochrome surfaces with one blue accent
- edges drawn with shadow rings instead of borders
- Geist at a single weight, with Geist Mono only for machine data

## What's here

[`docket-style.md`](docket-style.md) is the whole style guide. Paste it into Claude Code or any coding agent, then describe the screen you want. It contains:
- the tokens
- the full `globals.css`, for light and dark mode
- component recipes
- interaction states
- a final checklist

## Using the style in a project

1. Install Tailwind CSS v4 and the Geist fonts.
2. Copy the `globals.css` block from `docket-style.md` into your app.
3. Give your agent the whole guide along with the request.

The guide marks anything that wasn't in the original reference as *(derived)*.
